# YAMNet (TensorFlow.js)

Google's YAMNet audio event classifier (AudioSet ontology, 521 classes), TensorFlow.js graph-model
conversion as published on TensorFlow Hub / Kaggle Models (google/yamnet/tfJs/tfjs/1).

Licensed under the Apache License, Version 2.0: https://www.apache.org/licenses/LICENSE-2.0

Used here, unmodified, to tell which instruments and genres a recording contains
(src/audio/instruments.js). Class indices follow yamnet_class_map.csv from
https://github.com/tensorflow/models/tree/master/research/audioset/yamnet
